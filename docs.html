Install netch 1

netch 1 is discontinued and unsupported — downloads aren't offered directly from this page anymore. If you still want it, there's a warned download available on the Why? page. NetchLang 2 is coming soon and will be the actively developed version.

Your first program

Every netch file starts with one required line, similar to how HTML starts with <!DOCTYPE html>:

<using.netch>

print("hello world")

Save that as hello.netch and run it:

netch hello.netch

Variables don't need quotes, even for text:

name = jake
print(name)

And functions read like plain instructions:

function greet():
    print("hey there!")

run(greet)

Building a window app

Add a second header line to unlock real desktop apps — buttons, text boxes, images, and more:

<using.netch>
<window.using>

window.title("My First App")
window.size(400, 300)
window.theme("dark")

window.button.save = action print("saved!")
button.save.round(10)

Want a full working example? Here's a notepad — type in the box, click Save, click Open later and your text comes back:

<using.netch>
<window.using>

window.title("My Notepad")
window.textbox.editor

window.button.save
window.button.open

while true:
    if button.clicked(save):
        write(editor, "notes.txt")
    if button.clicked(open):
        read("notes.txt", editor)

Want to build this visually instead of typing coordinates by hand? Use netch builder — drag widgets onto a canvas and it writes the code for you.

Building a real calculator

A genuine working calculator — digit buttons, +, −, ×, ÷, and equals. This is a good one to study since it shows off functions with parameters, run(function(arg)), and reading/updating a shared display variable.

<using.netch>
<window.using>

window.title("Calculator")
window.size(240, 320)

display = "0"
first_number = 0
pending_op = ""

window.text.screen = display
text.screen.position(20, 20)
text.screen.fontsize(28)

function refresh():
    window.text.screen = display

function press_digit(d):
    if display == "0":
        display = d
    else:
        display = display + d
    run(refresh)

function press_op(o):
    first_number = number(display)
    pending_op = o
    display = "0"
    run(refresh)

function press_equals():
    second_number = number(display)
    if pending_op == "/":
        if second_number == 0:
            display = "Error"
            pending_op = ""
            run(refresh)
    if pending_op == "+":
        result = first_number + second_number
        display = result
    if pending_op == "-":
        result = first_number - second_number
        display = result
    if pending_op == "*":
        result = first_number * second_number
        display = result
    if pending_op == "/":
        if second_number != 0:
            result = first_number / second_number
            display = result
    pending_op = ""
    run(refresh)

function press_clear():
    display = "0"
    first_number = 0
    pending_op = ""
    run(refresh)

window.button.b7 = action run(press_digit(7))
button.b7.position(20, 70)
button.b7.size(45, 45)

window.button.badd = action run(press_op(+))
button.badd.position(170, 220)
button.badd.size(45, 45)
button.badd.color = "#3a3b44"

window.button.beq = action run(press_equals)
button.beq.position(20, 270)
button.beq.size(195, 45)
button.beq.color = "#a3e635"

' ... repeat the same pattern for buttons 0-9, subtract, multiply, divide, and clear

The full file (all 20 buttons wired up) is available to download here — this snippet is trimmed so the pattern is easy to follow rather than showing every near-identical button.
